# Kadri Hospitals Website

A modern, responsive multi-specialty hospital website. It shows medical departments and specialists, and lets patients book appointments online.

**Live demo:** https://kadrihospitals-ronak-c77739.netlify.app/

## Features
- Department and specialist listings
- Doctor detail pop-ups
- Online appointment booking
- Login modal
- Responsive design

## Tech Used
React, TypeScript, Vite, CSS

## Run Locally
1. Clone the repo
2. `cd kadri-hospitals`
3. `npm install`
4. `npm run dev`
